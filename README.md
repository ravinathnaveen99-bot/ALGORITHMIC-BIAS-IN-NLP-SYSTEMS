# ALGORITHMIC-BIAS-IN-NLP-SYSTEMS
This mini project presents a systematic study of algorithmic bias in Natural Language Processing (NLP) systems. Text-based machine learning models are now used to score sentiment, moderate toxic content and screen job applications, yet documented cases show that they can learn and amplify the prejudices present in their training data. The project first reviews well-known real-world failures, including a resume screening tool that penalised the word 'women's', toxicity classifiers that flagged harmless sentences containing identity terms, and hate-speech detectors that over-flagged African-American English.
To study these failures in a controlled and reproducible way, two bias-injected text datasets were generated in Python: a sentiment/toxicity dataset in which identity terms such as 'muslim' or 'gay' co-occur with negative labels, and a resume dataset whose historical hiring labels discriminate against female candidates. A TF-IDF with Logistic Regression pipeline was trained on each dataset and audited using fairness metrics: false positive rate gap, disparate impact ratio, equal opportunity difference and counterfactual flip rate. Three mitigation strategies were then implemented and compared: identity masking / anonymisation, Counterfactual Data Augmentation (CDA) and Reweighing.
Averaged over five random seeds, all models achieved accuracy above 86%, with the debiased sentiment models reaching 92.2% and the best resume model reaching 88.9% accuracy against merit labels. The sentiment false positive rate gap fell from 0.178 to 0.010, and the resume disparate impact ratio rose from 0.62 to 0.99 with anonymisation. The project uses only numpy and scikit-learn and runs on any system with Python 3.
